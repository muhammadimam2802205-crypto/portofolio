# Portofolio Muhammad Imam

Situs portofolio pribadi yang menampilkan proyek web, backend, dan sistem informasi yang saya kerjakan. Setiap proyek diambil langsung dari repository GitHub dan dilengkapi deskripsi, teknologi, fitur, serta status pengerjaan.

## Teknologi

- React 19 + Vite
- React Router
- Tailwind CSS
- Motion (animasi)
- lucide-react (ikon)

## Menjalankan proyek

```bash
npm install
npm run dev
```

Build produksi:

```bash
npm run build
npm run preview
```

Lint:

```bash
npm run lint
```

## Struktur konten

- `src/data/projects.js` — data proyek, status, dan tautan repository
- `src/components/` — bagian halaman (Hero, About, Projects, Skills, Contact)
- `src/pages/ProjectDetail.jsx` — halaman detail proyek
- `public/projects/` — cover proyek
- `public/logos/` — logo teknologi yang di-host sendiri
